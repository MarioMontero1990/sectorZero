## Sobre el proyecto
Sector Zero es una aplicación web full-stack desarrollada como proyecto final para el ciclo de Desarrollo de Aplicaciones Web (DAW). El sistema interactúa con hardware físico para capturar tiempos milimétricos, calcular velocidades reales y gestionar competiciones y torneos en circuitos físicos de slot.

## Tecnologías utilizadas
* **Backend:** Python
* **Base de Datos:** PostgreSQL / SQLite
* **Hardware:** Microcontrolador Arduino (C++) y sensores infrarrojos FC-51
* **Frontend:** HTML, CSS, JavaScript
